### 什么是「念来」？
念来（Evoke）是专为 Mac 深度专业工作者打造的原生空间工作台与应用切换器。告别传统横向跑道式的连击切换，纯 Swift 原生打造，按住 `⌥` 呼出 360° 磨砂质感圆盘，让所有常用应用环绕指尖，瞬念即达。

### 七大核心超能力
- **360° 空间径向切换**：按住修饰键唤出圆盘，建立稳定的物理方位肌肉记忆，松开瞬间直达目标窗口。
- **⌥ 冲突规避·随心豁免**：⌥ 是 macOS 大量系统快捷键的组成部分（Finder 右键菜单「拷贝为路径名」、终端 meta 键、⌥+拖拽=复制）。在设置「触发 → 豁免的应用」加入 Finder、终端等即可完全豁免；右键菜单打开、任意鼠标键按住、或按 `⌘⌥`/`⌃⌥` 组合键时也会自动抑制呼出——系统 ⌥ 快捷键永不被误弹的圆环打断。
- **任务现场一瞬归位**：按下 `⌃⌥S` 秒级捕获全屏幕窗口布局；点击底部专属胶囊，所有窗口如积木般原样归位。
- **24 格超自由分屏**：抓取窗口标题栏轻轻一摇（Shake-to-Snap），全屏 6×4 高光网格即刻浮现，任意矩形划选吸附平铺。
- **4K 巨幕画廊与视窗透视**：鼠标悬停即可浮现视窗小卡并实时透视物理内存；按 `Space` 展开原生 4K 巨幕，`← / →` 穿梭同应用多窗口。
- **中心黑洞引力粉碎**：闲置或高耗内存应用顺手拖入中央黑洞吞噬退出，或悬停直接按下 `⌘Q` 零激活秒关。
- **硬核纯原生工程底座**：纯 AppKit + SwiftUI 原生打造，拒绝 Electron 资源黑洞，常驻内存小于 18MB，待机 CPU 0.0%。
